Simple Calculator

A Java-based calculator that performs basic arithmetic operations. It uses a menu-driven approach to allow users to select operations and perform calculations.

How I Built It

  1. Identified the basic calculator requirements and arithmetic operations.
  2. Designed a menu-driven interface for selecting operations.
  3. Implemented addition, subtraction, multiplication, division and modulus.
  4. Used methods and loops to organize the program and allow repeated calculations.
  5. Added input handling and division-by-zero protection.
  6. Tested the operations using different inputs and JUnit tests.

Technologies Used

  • Java
  • Apache Maven
  • JUnit 5
  • IntelliJ IDEA / Visual Studio Code

Banking System

A Java-based banking application developed as a practical learning project. Its purpose is to explore how banking software handles user accounts, financial operations, data management and transaction records.

How I Built It

  1. Identified the fundamental requirements of a banking application.
  2. Planned the application structure using object-oriented programming principles.
  3. Designed the account and transaction-related components.
  4. Explored database integration and persistent data storage.
  5. Worked on input validation, transaction handling and separation of responsibilities.
  6. Reviewed the application structure to understand how real-world banking systems are organized.

Technologies Used

  • Java
  • Object-Oriented Programming (OOP)
  • SQLite
  • JDBC
  • Apache Maven
  • Git and GitHub
